# ADR-003: معماری رابط کاربری وب فارسی/RTL و جایگزینی SSE با نظرسنجی کوتاه‌مدت بدون حالت
- **وضعیت:** پذیرفته‌شده
- **زمینه:** رابط کاربری باید فارسی راست‌به‌چپ واقعی، دسترس‌پذیر و دارای افشای تدریجی باشد و در عین حال اتصالات وب نباید نخ‌های سرور و استخر تراکنشی PgBouncer را برای مدت طولانی قفل کنند.
- **تصمیم:** پیاده‌سازی SPA واکنش‌گرا (`React + TypeScript`) با خواص منطقی CSS و ایزولاسیون دوجهته متون LTR؛ حذف `Server-Sent Events (SSE)` در MVP و استفاده از مسیر سبک بدون حالت `GET /api/v1/workspaces/{wsId}/events/poll` با بازه تطبیقی و احترام به `Page Visibility API`.
- **پیامدها:** سادگی استقرار پشت هر پروکسی معکوس، مصرف ثابت اتصالات و حفظ پاسخ‌گویی زیر ۵۰۰ میلی‌ثانیه (`p95 = 131.77 ms` در `SPK-10`).
